Formulas & Operations

Arithmetic: + addition | − subtraction | * multiplication | / division | ^ exponent

Common formulas:

  • SUM(range) — adds values
  • AVERAGE(range) — calculates the mean
  • COUNT(range) — counts numbers
  • COUNTA(range) — counts non-empty cells
  • MAX(range) — finds the largest value
  • MIN(range) — finds the smallest value
  • IF(condition, value_if_true, value_if_false) — returns a result based on a condition
  • COUNTIF(range, criterion) — counts cells matching a criterion
  • SUMIF(range, criterion, sum_range) — adds values matching a criterion
Example: =SUM(B2:B10)
